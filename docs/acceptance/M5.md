# M5 验收记录

## 结论

- 代码定义完成，按用户要求未编译、未依赖具体运行环境。
- M5 后具备 Android/Windows 客户端与服务端的完整联调源码，但不是生产发布完成；签名安装包、HTTPS 部署、备份监控和安全验收属于 M6。

## 已实现

- 登录与退出、系统安全存储 Refresh Token、401 单飞刷新并轮换 Token。
- 首页提交 `info/download/transcribe/full`，Android 分享文本预填后人工确认。
- 任务详情、分阶段进度、前后台差异轮询、取消和重试。
- 结果发布文案/口播文案复制，Markdown/TXT/meta/媒体下载和进度展示。
- 历史列表搜索、筛选、删除确认、最近 100 条离线缓存。
- 服务器地址、下载目录、通知、主题设置；Android/Windows 完成或失败本地通知。
- 服务端新增历史分页筛选与终态任务删除 API，补全 M5 契约。

## 未在本环境执行

- `flutter pub get`、格式化、静态分析、Widget/集成测试和双端构建。
- Android 真机分享 Intent、通知权限、下载目录；Windows Toast 与文件选择器验证。
- 与真实部署服务端、真实抖音作品和真实 ASR 密钥的端到端验收。

## M6 前用户需准备

1. 一台 Ubuntu 24.04 服务器和一个可解析到服务器的域名。
2. 阿里云 DashScope API Key、Paraformer 每分钟价格与可选词表 ID；启用备用时再提供 SiliconFlow Key。
3. 两个初始账号的用户名/显示名/强密码。
4. Android 正式签名 keystore；Windows 安装包证书或明确接受未签名内测包。
5. 一台 Android 设备和一台 Windows 10 1809+/Windows 11 电脑做最终验收。
