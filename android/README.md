# Luxury Capture Android

Kotlin 与 Jetpack Compose 原生客户端，最低支持 Android 11（API 30）。

使用 Android Studio 打开本目录。界面使用原生 Compose 实现，参考苹果分组列表的紧凑布局、配色与信息层级，保留 Android 的返回、菜单、权限和系统分享习惯。

## 开发与构建

- 沿用工程的 Android Gradle Plugin 9.2.1、Gradle Wrapper 9.4.1、Kotlin 2.2.10 与 Compose BOM 2026.02.01。
- Gradle 使用 JDK 21，编译使用已安装的 Android SDK 36，最低版本为 API 30，目标版本为 API 36。
- 首次 Gradle 同步会下载工程依赖；不需要 Flutter、Dart、NDK 或 CMake。

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

调试 APK 输出到 `app/build/outputs/apk/debug/app-debug.apk`。

## 使用

1. 启动现有 Go 服务端，在客户端填写设备能够访问的服务器地址。
2. 使用服务端已有账号或管理员生成的 CDK 登录，无公开注册入口。
3. 粘贴抖音分享文本，或从其他应用的系统分享面板发送文本到 Luxury Capture，再手动确认创建任务。

客户端通过现有 REST API 工作，视频解析、音频提取和云端转写均由服务端执行。切换服务器会退出登录并清除该账号的本机历史缓存。

## 功能

- 账号与 CDK 登录、自动续期、密码修改、设备会话管理、退出登录。
- 解析信息、图文 / 视频、提取背景音文案三种提取方式，一行展示并展开当前选项文字；转写自动下载并保留媒体，支持服务商选择、强制新任务、语言提示及热词。
- 每日任务额度、CDK 额度、管理员下发的操作权限。
- 紧凑任务列表、历史搜索、状态与动作筛选、分页加载、离线历史；任务默认每次加载 10 条，支持长按后确认删除，处理中任务提示先取消；轻量摘要加载、进度轮询、取消与重试。
- 视频未播放时封面裁切铺满卡片宽度，播放按原比例显示；支持沉浸横屏全屏、播放与缓冲进度、拖动定位、双击快进退和控件自动隐藏。图片和动图可点开后左右翻页，支持前后切换、页数提示及静图缩放。
- 视频、图片、动图、音乐、TXT、Markdown、元数据与图文 ZIP 下载；下载前确认、仅 Wi-Fi 选项、过期媒体提示。
- 原声优先下载服务端保存的音乐文件；没有有效文件时，重新读取任务中的原声地址后交给系统下载，不在本机记录中保存源地址或登录凭证。作品分享使用系统分享面板，相邻跳转按钮经确认后打开原网站。
- 下载管理位于“我的 → 服务与管理”；支持状态、进度、速度、取消、重试、重新下载、打开与分享。移除记录默认保留文件，可勾选同时删除本地文件；删除失败保留记录并提供手动处理提示。
- 管理员概览与趋势、用户与会话管理、全局任务筛选、任务批量操作。
- CDK 生成、额度修改、次数重置、轮换、吊销、删除及批量操作；新生成的密钥仅在当次结果中展示。
- “我的 → 服务与管理”提供下载管理和使用设置；管理员另可进入转写服务及 API 目录。使用设置区分本机动效、任务通知与服务端默认额度、功能权限；服务端配置同时影响网页及客户端。详情与管理配置子页统一由顶栏刷新当前内容。
- 外观默认跟随系统，顶栏图标可直接切换浅色或深色；动效与任务通知位于使用设置，保留通知权限处理和服务器连接检查。
- 界面功能图标统一使用 Feather 线性图标库；登录表单根据可用高度居中，小屏与键盘弹出时可滚动；启动使用圆环加载动画。

下载确认后交给系统 DownloadManager，保存到 `Downloads/LuxuryCapture`，离开页面后由系统继续传输。API 30 起无需存储权限；API 33 起首次登录且启用任务通知时请求通知权限，拒绝后可从设置页重新启用。

## 动效与运行边界

主页面直接切换并保留页面状态，取消切页重复拉取和整页交叉渲染，保留局部交互反馈，下载进度独立更新。提取页改用懒加载列表，小封面按缩略图尺寸解码，任务摘要补全与合并在后台进行；轮询复用未变化的任务对象，进度动画只在进度条中读取，减少整行重组。播放器使用 Media3 ExoPlayer，按需读取媒体分段，以短缓冲起播；初始化、控制、读取进度和释放由专用线程串行处理。任务首次加载读取含封面的作品信息，后续轮询使用轻量摘要并保留封面缓存；转写筛选同时覆盖旧 transcribe 和新 full 任务，按真实时间合并分页。关闭动效或关闭系统动画时缩短或禁用过渡。

任务在服务器后台运行。客户端只在前台轮询；任务通知基于观察到的状态变化，不提供常驻后台服务或独立推送。

登录令牌使用 AndroidKeyStore 加密，不保存账号密码。API Key 保存在服务端，客户端仅在管理员主动配置时发送，不做持久化。

真机上的登录、真实作品解析和云端转写需要可访问的服务端及对应服务配置；构建和单元测试不替代真机验收。
